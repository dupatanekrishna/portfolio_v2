Security labs

01

AWS WAF security

Terraform-managed Web ACL, managed rules, custom blocks, rate limiting, logs, alarms, false-positive tuning and narrow exceptions.

02

Policy as code

OPA/Rego and Conftest applied to Terraform plan JSON to deny insecure infrastructure patterns with CI-friendly exit codes.

03

IaC security scanning

Checkov-based detection and remediation for public SSH exposure and S3 security controls, including scoped exceptions.

04

End-to-end security gates

Unit tests, coverage, secret scanning, SAST, SCA, IaC scanning, container security, DAST and optional SonarQube quality gates.

Delivery decision
The focus is on control behavior and evidence: what blocks, what warns, how false positives are handled, and how failures are investigated.

Engineering outcomes

  • Design preventive and detective security controls.
  • Tune WAF rules using logs, labels and narrow exceptions.
  • Apply OPA/Conftest and Checkov to infrastructure policy.
  • Build blocking and advisory security gates in CI/CD.
  • Reason about SAST, SCA, secret scanning, container scanning and DAST.
  • Troubleshoot scanner failures, false positives and enforcement behavior.
